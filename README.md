## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties (Variables for colors and typography)
- Flexbox / CSS Grid (For responsive layout)
- Mobile-first workflow
- Media Queries (For desktop adaptation)

### What I learned

Through this project, I solidified my understanding of creating responsive layouts without relying on JavaScript. I focused heavily on structuring semantic HTML and using CSS Flexbox/Grid to seamlessly transition the component from a single-column mobile view to a two-column desktop view. 

I also practiced using `hsla()` color values to match the exact gradient overlays provided in the design specifications.
